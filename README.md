# Grafo de conocimiento · 2º Big Data

Mapa interactivo de todo lo aprendido en 2º de Big Data: 2.677 conceptos y 4.277 relaciones,
agrupados en 8 áreas. Pasa el ratón por un punto para ver sus conexiones, busca conceptos
o filtra por área.

Solo se muestran los nombres de conceptos técnicos; el resto de nodos aparece como
"Concepto de <área>".

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `grafo-bdata2`.
2. Sube los archivos de esta carpeta (`index.html`, `data.js`, `README.md`):
   "Add file" → "Upload files".
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch",
   Branch: `main` y carpeta `/ (root)` → Save.
4. Al cabo de un minuto estará en `https://<tu-usuario>.github.io/grafo-bdata2/`.

Construido con graphify, Python y Sigma.js.
